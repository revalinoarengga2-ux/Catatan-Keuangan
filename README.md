# Catatan Keuangan — Demo Publik

Dashboard GitHub Pages interaktif dengan **data fiktif**, tanpa data keuangan pribadi.

Fitur: ringkasan pemasukan/pengeluaran, grafik bulanan, pencarian, filter, ekspor CSV, cetak PDF.

## Privasi
Tidak ada file Excel asli, nomor rekening, saldo atau transaksi asli. Semua transaksi dibuat secara sintetis di `index.html`.

## Publikasi
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

Catatan: repository ini saat pengunggahan berstatus **private**. Ketersediaan GitHub Pages untuk repository private bergantung pada paket akun. Jika Pages tidak dapat diaktifkan, publikasi memerlukan repository publik; pastikan hanya versi demo yang dipublikasikan.
